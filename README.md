## About This Project
This project was built using the `dreeve-wahoo-connector` as a foundational template to create a Zwift equivalent. Its setup is even more straightforward: you simply provide your Zwift credentials, and the service operates in exactly the same automated fashion.

Lacking the specific programming language expertise and the time required to build this migration from scratch, I leveraged Google Antigravity to write the implementation and guided the AI entirely by providing comprehensive technical and functional requirements.

While I understand that AI-generated code can be a controversial topic, without the assistance of it, this tool simply wouldn't exist.
